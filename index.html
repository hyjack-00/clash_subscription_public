分组用法

在 Clash 中选择“通用组”，再从中选择 美国静态中转、美国组、亚洲组或各来源后端组。

AI组已移除，需要 AI 流量时使用通用组。美国静态中转先通过美国组选出的节点，再连接静态代理；美国和亚洲组在客户端运行时每 5 分钟检测一次。

流程与名词
私有：上游订阅与规则↓ GitHub Actions 合并、重构并加密↓ 公开：GitHub 仓库与 Pages 展示↓ Cloudflare Worker 解密并提供下游订阅↓ Clash 客户端
  • 上游订阅：供应商提供的一个或多个私密链接。
  • 下游订阅：Cloudflare Worker 解密后供 Clash 读取的合并配置；完整订阅地址包含下游密钥，必须保密。
  • 蓝色代表私有仓库，绿色代表公开仓库，橙色代表 Cloudflare。
管理入口
  • 更换上游订阅：私有仓库 Secrets 中更新 UPSTREAM_SUB_URLS，每行 NAME LINK；空链接会忽略，不要公开链接。
  • 修改规则：编辑后台 Prompt，提交后运行更新。Agent 逐个判断美国、香港或其他地区并整理上游规则；通用组可选择 美国静态中转、美国组、亚洲组或各来源后端组。
  • 立即刷新：更新任务 → Run workflow → 选择 main → Run workflow；默认每 6 小时自动运行。
  • 配置 Cloudflare：Cloudflare 控制台 · Worker 部署说明。
